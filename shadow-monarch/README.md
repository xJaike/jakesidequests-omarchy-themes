# Shadow Monarch

Solo Leveling desktop theme: obsidian surfaces, monarch violet and mana cyan.

Apply: `omarchy theme set shadow-monarch`

Previous theme: Cloud Vs Rufus Wallpaper
Restore: `omarchy theme set "Cloud Vs Rufus Wallpaper"`

Wallpaper generated with the built-in imagegen tool. See wallpaper-prompt.txt for its prompt.
